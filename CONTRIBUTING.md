# Как вносить изменения

Эта база — git-репозиторий. Работай через ветки, не правь `main` напрямую.

## Добавить новый промпт
1. Создай ветку: `git checkout -b feat/<короткое-название>`
2. Положи файл в подходящую тематическую папку (или создай новую, если нет подходящей).
   Имя файла — латиницей, kebab-case, с расширением `.md` (или `.json` для конфигов).
3. Обнови `INDEX.md` (добавь описание и оригинальное имя, если было).
4. Commit: `git commit -m "feat: добавить промпт <что>"`
5. Push + merge в `main`.

## Править существующий промпт
1. Ветка `fix_ai/<название>` или `refactor_ai/<название>`.
2. Правки + commit с понятным сообщением.
3. Merge. История изменений остаётся в git.

## Синхронизация с Диском
Диск — read-only источник. Чтобы обновить базу из Диска заново,
используй скрипт навыка `google-drive-service-account` (см. `~/.hermes/skills/...`)
и перенеси файлы вручную сюда через ветку `chore_ai/sync-<дата>`.

## Соглашения
- Один промпт = один файл.
- Тематические папки, не «по месту хранения».
- Описания в `INDEX.md` на русском.
- Не коммить служебное (`.vscode`, `applet_access_history.json`) как промпты — клади в `meta/`.
