(папка «Промты для языковых моделей» в общей папке «Hermes Agent») в локальный
git-репозиторий.

- **Создана:** 2026-08-21 17:23 UTC
- **Источник:** Google Drive (service-account, read-only), folder `1iMcKFwx3IYDstMLczhGq_6FMG5QUgxxz`
- **Количество промптов:** 13
- **Версия контроля:** git

## Зачем git
Промпты — это текст, который эволюционирует. Git даёт:
историю изменений (кто/когда/что поменял), безопасный эксперимент через ветки,
и лёгкое сравнение версий (`git diff`). Репозиторий — единственный источник
правды локально; Диск остаётся архивом-источником (read-only для нас).

## Структура
Промпты сгруппированы по **темам** (а не по исходным папкам Диска, которые
были смешанными — например «Google AI Studio» это место хранения, не тема).

```
prompts-kb/
├── career/                           # Карьера и обучение
├── programming/                      # Программирование
├── hardware-design-and-verification/ # Аппаратная разработка и верификация
├── ai-practice/                      # Практика AI
├── legal/                            # Юриспруденция
├── meta/                             # Служебное: конфиги апплетов (не промпты)
├── README.md                         # Этот файл
├── INDEX.md                          # Полный индекс со описаниями
└── CONTRIBUTING.md                   # Как добавлять/править промпты
```

## Быстрый старт
Просто открой нужный `.md` файл и скопируй содержимое в чат/инструмент.
Каждый файл — самодостаточный промпт (или image-prompt).

Подробный индекс — в [INDEX.md](INDEX.md).
Как вносить изменения — в [CONTRIBUTING.md](CONTRIBUTING.md).
